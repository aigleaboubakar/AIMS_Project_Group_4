## One bug we had and how we fixed it

One of the main problems we had was handling edge cases in the functions.

For example:
- if `n <= 0`, the probability should be `0`
- if `n > days`, the result should be `1`
- if `trials <= 0`, the simulation should return `0`

At the beginning, the code did not always manage these cases correctly, which could cause invalid results. To fix this, we added simple checks at the start of the functions. This made the program more stable and prevented wrong values from being calculated.
